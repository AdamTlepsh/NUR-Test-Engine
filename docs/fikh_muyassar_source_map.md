# Fikh al-Muyassar Source Map

## Fixed Source

All study materials, questions, answers, and distractors for the Fikh al-Muyassar module must be based only on this PDF:

`/Users/adamtlepsev/Downloads/Fikh/«Фикх_аль_Муяссар»_—_облегчённое_изложение_ханафит_260715_234107.pdf`

No external sources, later additions, personal explanations, or cross-chapter assumptions are allowed when creating questions.

## App Chapter Model

The app should treat each major book section from the PDF as one learning chapter:

1. `tahara` - Книга первая: Очищение
2. `salah` - Книга вторая: Намаз
3. `funerals` - Книга третья: Похороны
4. `fasting` - Книга четвертая: Пост
5. `zakat` - Книга пятая: Закят
6. `hajj` - Книга шестая: Хадж
7. `qurban` - Книга седьмая: Жертвоприношение (курбан)

Introductory material already included with the first chapter may remain there, because the current application uses the first chapter as the entry point into the book.

Book page numbers below are taken from the PDF table of contents. For the main text, the PDF page is usually one page higher than the printed book page.

## Question Rules

- Questions are created only from the text of the corresponding chapter.
- Each chapter has three levels: basic, advanced, expert.
- Each question has exactly four answers: A, Б, В, Г.
- There is always exactly one correct answer.
- Distractors must be realistic, topic-related, and similar in style and length.
- Do not create a question when the chapter text does not allow an unambiguous answer.
- Cover the whole chapter without repeating the same fact in different words.
